Evaluation Framework Proposal

Two-Level Media Classification

Resolving the binary gap in Tako media evaluation by separating query-level intent from response-level delivery.

Tako Evaluation | June 2026

The Problem

One Label. Entire Response.

Current Approach

Media type is determined once at the query level and applied as a blanket label to the entire response.

Evaluators answer: "Should this query have media?" instead of "Did the response use media appropriately?"

Root Cause

The "Purely" Problem

Guideline Says:

"Purely Rule-based, Policy, or Procedural Information"

  • "Purely" implies the entire response must be procedural to qualify
  • But Tako often extends beyond the literal query
  • Evaluators argue on semantics, not media quality
Real Example

Requirements query — but response extends scope

  • Section 1: Requirements (procedural, no media needed)
  • Section 2: Selection Process (media adds value here)
  • Current score = 0. But the response is not useless.
Proposal

Two-Level Classification

Level 1: Query

"Does the user's intent require media?"

Determined by: Query alone

Level 2: Response

"Did the response place media where it adds value?"

Determined by: Response scope

Separates "what the query needs" from "what the response delivers."
